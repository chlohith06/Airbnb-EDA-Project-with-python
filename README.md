# 🏠 Airbnb Exploratory Data Analysis (EDA) using Python

## 📖 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on the **New York City Airbnb Listings** dataset using Python. The analysis aims to understand pricing patterns, room type distribution, host activity, customer reviews, and the geographical spread of Airbnb properties across different boroughs of New York City. The project transforms raw data into meaningful insights through data cleaning, visualization, and statistical analysis.

---

## 🎯 Objectives

- Perform data cleaning and preprocessing.
- Handle missing values and duplicate records.
- Analyze Airbnb pricing trends across different boroughs.
- Explore the distribution of room types and property listings.
- Study relationships between price, reviews, and availability.
- Visualize the geographical distribution of Airbnb listings.
- Generate business insights using exploratory data analysis.



## 🛠️ Technologies Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Exploratory Data Analysis

### Data Cleaning
- Loaded the dataset into Pandas.
- Checked dataset dimensions and data types.
- Handled missing values.
- Removed duplicate records.
- Converted columns into appropriate data types.

### Univariate Analysis
- Distribution of listing prices.
- Room type distribution.
- Listings by neighbourhood group.
- Review count analysis.
- Availability analysis.

### Bivariate Analysis
- Price comparison across boroughs.
- Price variation by room type.
- Relationship between reviews and price.
- Availability based on room type.

### Multivariate Analysis
- Correlation analysis.
- Pair plots of important numerical features.
- Correlation heatmap.

### Geographical Analysis
- Distribution of Airbnb listings using latitude and longitude.
- Listing density across NYC boroughs.
- Location-wise price comparison.

---

## 📈 Key Insights

- Manhattan has the highest average Airbnb prices.
- Brooklyn has the largest number of Airbnb listings.
- Entire homes/apartments are generally more expensive than private or shared rooms.
- Listings in prime locations receive more reviews and higher prices.
- A small number of hosts manage multiple Airbnb properties.
